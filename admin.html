En GitHub

Guarda en el repositorio del catálogo y la página se actualiza sola. Necesita una clave de acceso.

¿Cómo creo la clave?
  1. En GitHub, entrá a Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Ponele un nombre, por ejemplo Panel AUVIN, y elegí cuánto dura.
  3. En Repository access elegí Only select repositories y marcá el repositorio del catálogo.
  4. En Permissions → Repository permissions, buscá Contents y elegí Read and write.
  5. Tocá Generate token, copiá la clave y pegala acá arriba. GitHub la muestra una sola vez.

Perfumes

Productos del catálogo completo que todavía no tienen foto (en la página no se muestran). Tocá Cargar foto: se le pone solo el fondo de estudio. Si no tenés foto con fondo blanco, usá el pedido para ChatGPT (está en el editor de “Agregar perfume”).

Cómo cargar un perfume nuevo
  1. Tocá Agregar perfume y elegí la foto. Lo ideal: el frasco sobre fondo blanco, como las fotos de las marcas en internet. Si no tenés una, adentro del editor está el pedido para que ChatGPT te la haga.
  2. Completá marca, nombre y género. Lo demás (tamaño, precio, notas) es opcional.
  3. El 3D se arma solo a partir de la foto. Si no te convence, destildá “Mostrar el frasco en 3D”.
  4. Tocá Guardar en el editor y después Guardar o Publicar abajo.

    Nuevo perfume

    Foto

    Elegí o arrastrá una foto del perfume. Si tiene fondo liso (blanco o claro), se recorta y se pone sobre el fondo de estudio.

    Fondo

    ¿Tu foto no tiene fondo blanco? Pedile a ChatGPT que la limpie
    1. En ChatGPT adjuntá la foto del perfume (da igual el fondo que tenga).
    2. Copiá este pedido, pegalo y mandalo.
    3. Descargá la imagen que te da y elegila acá con el fondo en Automático: el panel le pone el mismo fondo de estudio que al resto y arma el frasco 3D.

    Si ChatGPT cambia algo del frasco, respondele: “El frasco tiene que ser idéntico al de mi foto. Corregí solo eso y dejá el fondo blanco”.
